# Credit Card Transaction & Customer Analytics Dashboard

## 📌 Overview

An interactive Power BI project designed to analyze credit card transactions and customer-level information through business-focused dashboards and detailed customer analysis.

The project combines transaction analysis with customer insights to provide a consolidated view of financial performance, customer behavior, and spending patterns.

---

## 📊 Dashboard Structure

The Power BI report contains three main pages:

### 1. 💳 Credit Card Dashboard

Provides an overview of credit card performance and key transaction-related metrics.

### 2. 👤 Customer Details

Provides detailed customer-level information for deeper analysis of individual customer records.

### 3. 💰 Credit Card Transaction Report

Focuses on transaction-level analysis and financial performance across different dimensions.

---

## 🔎 Analysis Areas

The project covers analysis related to:

- Credit card transactions
- Revenue performance
- Customer demographics
- Customer behavior
- Spending patterns
- Transaction performance
